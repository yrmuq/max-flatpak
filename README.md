## ⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ

Это **НЕОФИЦИАЛЬНЫЙ** пакет мессенджера MAX, не связанный с разработчиками VK или создателями оригинального приложения. 

Данный репозиторий автоматически перепаковывает официальный Linux-клиент MAX с `download.max.ru` в изолированную песочницу Flatpak с максимальной защитой данных пользователя.

---

## 🔒 Особенности безопасной сборки

- **Полная изоляция личных папок**: приложение **НЕ ИМЕЕТ** прямого доступа к вашим файлам, документам и загрузкам. Передача и сохранение файлов происходит **исключительно** через системный диалог выбора файлов (XDG Desktop Portal).
- **Нативная поддержка Wayland**: современный графический протокол с улучшенной безопасностью и производительностью.
- **Полнофункциональные звонки**: аудио- и видеозвонки работают через PipeWire с поддержкой веб-камеры и демонстрации экрана.
- **Системная интеграция**: уведомления, иконка в системном трее, автозапуск.
- **Автоматическое обновление**: при установке через репозиторий обновления приходят автоматически через `flatpak update` или графические менеджеры пакетов (GNOME Software, KDE Discover).

## 📦 Установка

### Способ 1: Через репозиторий (рекомендуется, с автообновлением)

```bash
# Подключить репозиторий
flatpak remote-add --user --no-gpg-verify max-repo https://yrmuq.github.io/max-package/

# Установить MAX
flatpak install --user max-repo ru.max.Unofficial
```

**Преимущества:**
- Автоматические обновления через `flatpak update`
- Поддержка графических менеджеров пакетов (KDE Discover, GNOME Software)
- Минимальный размер загрузки при обновлениях

### Способ 2: Одиночным файлом из Releases

```bash
# Скачайте MAX.flatpak со страницы Releases:
# https://github.com/yrmuq/max-package/releases/latest

# Установите скачанный файл
flatpak install --user MAX.flatpak
```

**Преимущества:**
- Не требует подключения репозитория
- Возможность офлайн-установки

## 🛠️ Технические детали

- **App ID**: `ru.max.Unofficial`
- **Runtime**: `org.freedesktop.Platform 24.08`
- **Base**: `org.electronjs.Electron2.BaseApp 24.08`
- **Песочница**: максимально строгая изоляция, доступ к файлам только через портал
- **Права доступа**:
  - Сеть (для обмена сообщениями)
  - Аудио/видео (PulseAudio, веб-камера)
  - Демонстрация экрана (PipeWire)
  - Уведомления
  - Системный трей
- **Исходный код**: все конфигурационные файлы и скрипты сборки доступны в этом репозитории
- **Автоматизация**: GitHub Actions проверяет наличие новых версий каждые 6 часов и автоматически собирает обновления

## ⚡ Автоматическая сборка

Репозиторий использует GitHub Actions для автоматической проверки обновлений каждые 6 часов. При появлении новой версии на `download.max.ru` автоматически:

1. Скачивается оригинальный RPM-пакет
2. Извлекаются файлы и перепаковываются в Flatpak с жесткой песочницей
3. Публикуется в GitHub Pages (для установки через репозиторий)
4. Создается релиз с одиночным `.flatpak` файлом

Вся сборка прозрачна и воспроизводима — все исходники и логи доступны публично.
